Devanagari, wider search

Eight faces this time, all verified to carry both scripts. Same card, same kumkum palette, same test: ओंकार आणि स्नेहल on the card, and a vendor's Rules underneath at the size someone actually reads them.

Rozha is ringed in gold so you can hold the others against it. The last card is a different proposition — Inknut Antiqua setting everything, English included, which would retire Playfair and leave you one family instead of a pair to maintain. I dropped fourteen other Devanagari families before rendering: Modak, Baloo 2, Khand, Kurale, Asar, Gotu, Jaini, Palanquin, Kadwa, Sumana, Sahitya, Halant, Laila and Noto Serif Devanagari — wrong register for an invitation, or correct but characterless.
