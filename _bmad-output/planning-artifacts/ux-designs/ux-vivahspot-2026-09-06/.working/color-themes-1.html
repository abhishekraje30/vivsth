Direction 1, with the volume up

Same invitation card, same serif, same square corners, same gold rule — the structure you liked is untouched. Only the colour changes, and it changes hard.

Every accent below carries a label that clears WCAG AA against it. On Marigold and Turmeric the accent is too light for white text, so the button label is dark ink instead — that isn't a style choice, it's prd.md:1353 applied forward.
