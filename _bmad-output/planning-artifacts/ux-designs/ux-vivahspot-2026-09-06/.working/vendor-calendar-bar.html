The 284px case, actually rendered

The sentence this file used to carry — "vertical ones never overlap" — was false, and it described a width this file never drew. With square cells and a uniform gap the horizontal and vertical overlaps are equal by construction: row pitch and column pitch are both cell + gap. So the honest rule is the one now in the stylesheet — the overlay is never wider than the column pitch, and the 44px floor is met by the cell, not by the overlay. Below a 44px pitch the cell cannot reach the floor, which is the bounded exception the phone month grid now carries (40×40, 2px gap, 42px pitch).
